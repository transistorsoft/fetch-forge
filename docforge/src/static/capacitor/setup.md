## Installation

=== "npm"

    ```bash
    npm install @transistorsoft/capacitor-background-fetch
    npx cap sync
    ```

=== "yarn"

    ```bash
    yarn add @transistorsoft/capacitor-background-fetch
    npx cap sync
    ```
